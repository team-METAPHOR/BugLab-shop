## 제거한 결함·정상 대조

- 쿠폰 API 최초 적용은 정상이다. 키보드가 포함된 혼합 장바구니에서도 재적용은 `409 COUPON_ALREADY_APPLIED`, 이력 1개다.
- 마우스 감소 후 서버 subtotal이 정상 재계산된다. 혼합 장바구니에서도 행 합계와 일치한다.
- 한정판 추천 진입 때 구매 영역의 이전 재고 상태를 유지하지 않는다. 품절 API 담기도 409로 거부한다.
- 허브 검색 빠른 담기 1클릭은 POST 1회·수량 1개·42,000원이다.
- 매트를 포함한 모든 상품의 찜 조회는 실제 UUID를 유지하고, 찜 목록 해제 후 서버에도 남지 않는다.
- 받침대를 포함한 모든 상품의 배송 팝업은 뒤로 가기 때 제거되고 배경 잠금이 해제된다.
- 전체 6개 → 키보드 2개 → 냉장고 0개·빈 결과 안내. 새로고침해도 빈 결과 정상.
- 비로그인 상세 찜 버튼은 기존 로그인 화면으로 이동한다.
- 초기화 후 qa1의 보호 API 접근은 401, qa2는 200이다. 인증 라우트의 익명 `/api/auth/me` 응답 형식 대신 보호 API로 세션 무효화를 검증했다.
- `/api/auth/me`는 익명·잘못된 세션·초기화된 세션에서 200과 `user: null`, 정상 세션에서 200과 해당 사용자 정보가 나오는지 서버 테스트로 확인한다.
- 잘못된 초기화 토큰 401, production 초기화 API 404, 미정의 장바구니 경로 404, 보호 API의 비로그인 접근 401을 확인했다.
