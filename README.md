# BugLab Shop

Vue 3 + Vite 기반 프런트엔드 프로젝트입니다.

## 개발 환경

- Node.js 20.19 이상 또는 22.12 이상
- npm
- 권장 에디터: VS Code + Vue - Official 확장

## 실행

```sh
npm install
npm run dev
```

## 빌드 및 미리보기

```sh
npm run build
npm run preview
```

## 프로젝트 구조

- `src/main.js`: Vue 앱 진입점
- `src/App.vue`: 루트 컴포넌트
- `src/assets/main.css`: 공통 스타일
- `vite.config.js`: 개발 서버 및 빌드 설정
